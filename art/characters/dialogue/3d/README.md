# Procedural 3D dialogue portraits

These are runtime assets generated by:

- `marketing/lib/build_3d_spacedoge.py`
- `marketing/lib/build_3d_alien.py`
- the shared `such-graphics` `creature3d` viseme contract

The checked-in set was rendered with Blender 5.2.0 LTS and clean
`such-graphics` commit `41bfa1dba95ef769dd46b25710623a13b023e19e`.

The app carries only the restrained `X`, `A`, `B`, and `F` shapes at 512×512.
`TalkingPortrait.gd` cycles those transparent PNGs, so mobile builds get the 3D
character performance without loading a live 3D scene or a video decoder.

Regenerate into `~/Build/such-moon-launch`, visually review there, and only then
promote the selected PNGs here. Use Blender `portrait` mode with:

```text
SG3D_CLOSEUP=1
SG3D_RES=512x512
SG3D_VISEMES=X,A,B,F
SG3D_OUT=<a directory under ~/Build/such-moon-launch>
```

Never point `SG3D_OUT` at this source directory.
