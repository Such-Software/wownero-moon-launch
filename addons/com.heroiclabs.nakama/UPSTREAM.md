# Nakama Godot SDK provenance

This directory contains the unmodified Nakama core from Heroic Labs'
Apache-2.0 licensed `nakama-godot` release `v3.4.0`, upstream commit
`14b7f7078a9822c15b0424624e4c883c87730cee`.

The source archive SHA-256 is
`b4a24adf027637a42ece8f09f240aa91ed5ba006dbdfd1ba48a1cbe92e0b1e34`.
Satori, sample/test projects, code generation tools, and .NET helpers are
intentionally not vendored. `config/nakama-godot-sdk.lock.json` pins every
included SDK and license file; app-local integration code lives outside this
directory.
