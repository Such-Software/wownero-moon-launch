# Such Moon Launch website

This is the intentional marketing/play surface for `moonlaunch.space`.
Commerce remains on the dedicated Medusa tenant; `/store` reports its
inactive setup status and contains no checkout.

The website consumes the Wownero brand projection pinned by
`config/app-platform-v1.json`. Local dependencies, builds, test output, and
deployment packaging belong under `~/Build/such-moon-launch/website`, not in
this directory.

The connected Sites project is recorded only in `.openai/hosting.json` after
creation. Preview deployments remain `noindex` until the reviewed DNS, TLS,
edge, rollback, Medusa, catalog, identity, entitlement, and restore gates are
complete.
